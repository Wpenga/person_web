# 嵌入式项目经验总结

## 项目概述

本文档总结了三个核心嵌入式项目的开发经验，涵盖串口屏显示系统、RS485温湿度采集系统和STM32多功能控制器。

---

## 项目一：串口屏网络状态显示系统

### 项目简介

实现路由器网络状态、电量和充电状态的实时显示系统，采用上下位机架构设计。

### 技术架构

```
┌──────────────────────────────────────────────────────────┐
│                      上位机 (Python)                     │
│  ┌─────────┐  ┌───────────┐  ┌──────────────────────┐   │
│  │网络状态 │→ │ 数据处理  │→ │ 串口通信协议封装     │   │
│  └─────────┘  └───────────┘  └──────────────────────┘   │
└──────────────────────────────────────────────────────────┘
                           │
                           ▼ Serial (UART)
┌──────────────────────────────────────────────────────────┐
│                      下位机 (串口屏)                      │
│  ┌──────────────────┐  ┌────────────────────────────┐   │
│  │ JY1560 串口屏    │←│ UI界面显示更新             │   │
│  └──────────────────┘  └────────────────────────────┘   │
└──────────────────────────────────────────────────────────┘
```

### 核心功能

| 功能模块 | 描述 | 实现方式 |
|---------|------|---------|
| 网络模式显示 | 显示路由器当前网络连接模式 | 通过API获取网络状态并解析 |
| 电量显示 | 实时显示电池电量百分比 | 读取系统电源状态 |
| 充电状态显示 | 显示充电中/已充满/未充电 | 检测充电状态变化 |
| 串口通信 | 上下位机数据交互 | 自定义帧协议 |

### 项目链接

- **下位机（串口屏）**: [JY1560_TJC_2inch](https://github.com/Wpenga/JY1560_TJC_2inch/tree/main)
- **上位机（Python）**: [router_and_input](https://github.com/Wpenga/router_and_input/tree/develop)

### 技术栈

- **硬件**: 淘晶驰JY1560串口屏
- **软件**: Python 3.x, pyserial
- **协议**: 自定义串口帧协议

## 项目二：ESP32-S3 RS485温湿度采集系统

### 项目简介

基于ESP32-S3单片机的温湿度数据采集系统，通过RS485总线获取传感器数据并更新到串口屏显示。

### 技术架构

```
┌─────────────────────────────────────────────────────┐
│              传感器层 (RS485总线)                    │
│  ┌──────────┐  ┌──────────┐  ┌─────────────────┐   │
│  │ 温湿度   │  │ 温湿度   │  │   其他传感器    │   │
│  │ 传感器1  │  │ 传感器2  │  │      ...       │   │
│  └────┬─────┘  └────┬─────┘  └────────┬────────┘   │
│       │             │                 │            │
└───────┼─────────────┼─────────────────┼────────────┘
        │             │                 │
        ▼             ▼                 ▼
┌─────────────────────────────────────────────────────┐
│            ESP32-S3 数据采集层                      │
│  ┌─────────────────────────────────────────────┐   │
│  │  RS485 Modbus协议解析 → 数据处理 → UART输出  │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
                          │
                          ▼ UART
┌─────────────────────────────────────────────────────┐
│            显示层 (淘晶驰4.3寸串口屏)               │
│  ┌─────────────────────────────────────────────┐   │
│  │           温度显示 │ 湿度显示                │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

### 核心功能

| 功能模块 | 描述 | 实现方式 |
|---------|------|---------|
| RS485通信 | 与多个传感器节点通信 | Modbus-RTU协议 |
| 数据采集 | 周期性读取温湿度数据 | FreeRTOS任务调度 |
| 数据转发 | 将传感器数据发送到串口屏 | UART串口通信 |
| 界面显示 | 实时更新温湿度数值 | 淘晶驰UI控件 |

### 项目链接

- **下位机（串口屏）**: [S327_TJC_4.3inch](https://github.com/Wpenga/S327_TJC_4.3inch/tree/main)
- **上位机（ESP32）**: [S318_Signal_Code_template](https://github.com/Wpenga/S318_Signal_Code_template/tree/S327-003)

### 技术栈

- **硬件**: ESP32-S3, RS485模块, 淘晶驰4.3寸串口屏
- **软件**: ESP-IDF, FreeRTOS
- **协议**: Modbus-RTU, 自定义串口协议

## 项目三：STM32多功能控制器（无人机地面站）

### 项目简介

基于STM32的多功能控制器，集成按键、LED灯、ADC摇杆等外设，支持UART和USB HID协议，可作为Joystick设备对接Mission Planner软件。

### 技术架构

```
┌──────────────────────────────────────────────────────┐
│                    外设层                            │
│  ┌─────────┐ ┌──────┐ ┌─────────┐ ┌────────┐ ┌─────┐│
│  │ 按键矩阵 │ │ LED │ │ ADC摇杆 │ │蜂鸣器 │ │ 其他││
│  └────┬────┘ └──┬───┘ └────┬────┘ └───┬────┘ └──┬──┘│
│       │         │          │          │         │   │
└───────┼─────────┼──────────┼──────────┼─────────┼───┘
        │         │          │          │         │
        ▼         ▼          ▼          ▼         ▼
┌──────────────────────────────────────────────────────┐
│               STM32 控制层                           │
│  ┌──────────────────────────────────────────────┐   │
│  │ UART通信 │ USB HID │ 摇杆校准 │ 指令解析    │   │
│  └──────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────┘
                          │
              ┌───────────┴───────────┐
              ▼                       ▼
    ┌─────────────────┐    ┌──────────────────┐
    │  UART串口更新   │    │  USB HID Joystick│
    │  (串口指令控制) │    │ (Mission Planner)│
    └─────────────────┘    └──────────────────┘
```

### 核心功能

| 功能模块 | 描述 | 应用场景 |
|---------|------|---------|
| 按键控制 | 可定制各类功能按键 | 无人机/无人船控制命令 |
| LED指示灯 | 状态指示与反馈 | 系统状态可视化 |
| ADC摇杆 | 模拟量输入与校准 | 飞行姿态控制 |
| USB HID | 作为Joystick设备 | 对接Mission Planner |
| 蜂鸣器控制 | 声音提示与报警 | 操作反馈与告警 |
| UART通信 | 串口指令更新外设状态 | 远程控制与状态查询 |

### 技术特点

1. **摇杆校准算法**：支持自动/手动校准，消除零点漂移
2. **指令系统**：自定义串口指令协议，支持实时状态查询和控制
3. **USB HID协议**：完整实现Joystick报告描述符
4. **低功耗设计**：支持多种省电模式

### 应用场景

- 无人机地面站控制
- 无人船遥控系统
- 工业自动化控制
- 机器人远程操控

### 技术栈

- **硬件**: STM32系列单片机
- **软件**: STM32 HAL库
- **协议**: USB HID (Joystick), 自定义串口协议
- **工具**: STM32CubeMX, Keil MDK

## 总结

| 项目 | 硬件平台 | 核心技术 | 应用领域 |
|------|---------|---------|---------|
| 串口屏网络状态显示 | JY1560串口屏 + Python | 串口通信, 协议设计 | 路由器状态监控 |
| RS485温湿度采集 | ESP32-S3 + 4.3寸屏 | RS485, Modbus | 环境监测 |
| STM32多功能控制器 | STM32 + USB HID | USB协议, HID | 无人机地面站 |

这三个项目展示了从简单串口通信到复杂USB协议实现的完整嵌入式开发能力，涵盖了上下位机协同、传感器数据采集、人机交互等多个技术领域。
