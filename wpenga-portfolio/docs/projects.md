# 嵌入式项目经验总结

## 项目概述

本文档总结了三个核心嵌入式项目的开发经验，涵盖串口屏显示系统、RS485温湿度采集系统和STM32多功能控制器。其中前两个项目采用上下位机架构设计。

---

## 项目一：JY1560串口屏网络状态显示系统

### 项目简介

完整的上下位机架构系统，实现路由器网络状态、电量、充电状态的实时监控与串口屏显示。

### 系统架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           上位机 (Python)                                  │
│  ┌─────────────────┐  ┌─────────────┐  ┌─────────────────────────────┐   │
│  │ 网络状态获取API  │→ │ 电源状态读取 │→ │ 串口通信协议封装与数据发送 │   │
│  └─────────────────┘  └─────────────┘  └─────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼ Serial (UART)
┌─────────────────────────────────────────────────────────────────────────────┐
│                           下位机 (串口屏)                                  │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  JY1560 淘晶驰串口屏 UI界面                                         │   │
│  │  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────────────────────┐    │   │
│  │  │网络模式   │ │ 电量显示 │ │充电状态  │ │ 自定义帧协议解析    │    │   │
│  │  │显示区域   │ │百分比    │ │指示图标  │ │ 与数据更新         │    │   │
│  │  └──────────┘ └──────────┘ └──────────┘ └─────────────────────┘    │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 上下位机分工

#### 上位机（Python）

| 功能模块 | 描述 | 实现方式 |
|---------|------|---------|
| 网络状态获取 | 获取路由器当前网络连接模式 | 通过系统API或网络接口查询 |
| 电量状态读取 | 读取系统电池电量百分比 | Windows/Linux电源管理API |
| 充电状态检测 | 检测设备充电状态 | 电源状态变化事件监听 |
| 串口协议封装 | 将数据封装为自定义帧格式 | 字节级协议设计 |
| 数据发送 | 将状态数据发送到串口屏 | pyserial库 |

**项目链接**: [router_and_input](https://github.com/Wpenga/router_and_input/tree/develop)

#### 下位机（串口屏）

| 功能模块 | 描述 | 实现方式 |
|---------|------|---------|
| UI界面设计 | 设计网络状态、电量、充电状态显示界面 | 淘晶驰串口屏开发工具 |
| 串口数据接收 | 接收上位机发送的状态数据 | 串口中断接收 |
| 协议解析 | 解析自定义串口帧协议 | 状态机解析 |
| 界面更新 | 根据接收数据更新UI显示 | 控件属性动态修改 |

**项目链接**: [JY1560_TJC_2inch](https://github.com/Wpenga/JY1560_TJC_2inch/tree/main)

### 通信协议

自定义帧格式：`0xAA + 长度 + 数据类型 + 数据 + 校验和 + 0x55`

### 技术栈

| 角色 | 硬件 | 软件 | 协议 |
|------|------|------|------|
| 上位机 | PC | Python 3.x, pyserial | 自定义串口帧协议 |
| 下位机 | 淘晶驰JY1560串口屏 | 淘晶驰TJC开发环境 | 自定义串口帧协议 |

## 项目二：S327 ESP32-S3温湿度采集系统

### 项目简介

基于ESP32-S3单片机的多节点温湿度采集系统，通过RS485总线获取传感器数据并实时更新到淘晶驰4.3寸串口屏显示。

│  │   节点1   │  │   节点2   │  │ 传感器   │  │                       │   │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘  └──────────┬────────────┘   │
│       │             │             │                    │                │
└───────┼─────────────┼─────────────┼────────────────────┼────────────────┘
        │             │             │                    │
        ▼             ▼             ▼                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                      上位机 (ESP32-S3)                                     │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────────────┐ │   │

│  │  │ 驱动模块    │  │ 协议解析    │  │                            │ │   │

└─────────────────────────────────────────────────────────────────────────────┘

### 上下位机分工

#### 上位机（ESP32-S3）

| 功能模块 | 描述 | 实现方式 |
|---------|------|---------|
| RS485驱动 | 控制RS485收发器 | GPIO控制DE/RE引脚 |
| Modbus-RTU协议 | 解析传感器数据 | 状态机协议解析 |
| 多任务调度 | 周期性采集多个传感器 | FreeRTOS任务 |
| 数据处理 | 数据校验与格式化 | 浮点数处理 |
| UART转发 | 将数据发送到串口屏 | ESP-IDF UART驱动 |

**项目链接**: [S318_Signal_Code_template](https://github.com/Wpenga/S318_Signal_Code_template/tree/S327-003)

#### 下位机（串口屏）

| 功能模块 | 描述 | 实现方式 |
|---------|------|---------|
| UI界面设计 | 设计温度、湿度、状态显示界面 | 淘晶驰TJC开发环境 |
| 串口数据接收 | 接收ESP32发送的传感器数据 | 串口中断接收 |
| 协议解析 | 解析自定义串口帧协议 | 状态机解析 |
| 界面更新 | 根据接收数据更新温湿度显示 | 控件属性动态修改 |

**项目链接**: [S327_TJC_4.3inch](https://github.com/Wpenga/S327_TJC_4.3inch/tree/main)

### 通信协议

| 层级 | 协议 | 说明 |
|------|------|------|
| 传感器通信 | Modbus-RTU | RS485总线，从站地址0x01-0x0F |
| 屏显通信 | 自定义协议 | UART，波特率115200 |

### 技术栈

| 角色 | 硬件 | 软件 | 协议 |
|------|------|------|------|
| 上位机 | ESP32-S3, RS485模块 | ESP-IDF, FreeRTOS | Modbus-RTU, 自定义串口协议 |
| 下位机 | 淘晶驰4.3寸串口屏 | 淘晶驰TJC开发环境 | 自定义串口协议 |

## 项目三：STM32多功能控制器（无人机地面站）

### 项目简介

基于STM32的多功能控制器，集成按键、LED灯、ADC摇杆等外设，支持UART和USB HID协议，可作为Joystick设备对接Mission Planner软件。

### 技术架构

```
┌──────────────────────────────────────────────────────┐
│                    外设层                            │
│  ┌─────────┐ ┌──────┐ ┌─────────┐ ┌────────┐ ┌─────┐│
│  │ 按键矩阵 │ │ LED │ │ ADC摇杆 │ │蜂鸣器 │ │ 其他││
│  └────┬────┘ └──┬───┘ └────┬────┘ └───┬────┘ └──┬──┘│
│       │         │          │          │         │   │
└───────┼─────────┼──────────┼──────────┼─────────┼───┘
        │         │          │          │         │
        ▼         ▼          ▼          ▼         ▼
┌──────────────────────────────────────────────────────┐
│               STM32 控制层                           │
│  ┌──────────────────────────────────────────────┐   │
│  │ UART通信 │ USB HID │ 摇杆校准 │ 指令解析    │   │
│  └──────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────┘
                          │
              ┌───────────┴───────────┐
              ▼                       ▼
    ┌─────────────────┐    ┌──────────────────┐
    │  UART串口更新   │    │  USB HID Joystick│
    │  (串口指令控制) │    │ (Mission Planner)│
    └─────────────────┘    └──────────────────┘
```

### 核心功能

| 功能模块 | 描述 | 应用场景 |
|---------|------|---------|
| 按键控制 | 可定制各类功能按键 | 无人机/无人船控制命令 |
| LED指示灯 | 状态指示与反馈 | 系统状态可视化 |
| ADC摇杆 | 模拟量输入与校准 | 飞行姿态控制 |
| USB HID | 作为Joystick设备 | 对接Mission Planner |
| 蜂鸣器控制 | 声音提示与报警 | 操作反馈与告警 |
| UART通信 | 串口指令更新外设状态 | 远程控制与状态查询 |

### 技术特点

1. **摇杆校准算法**：支持自动/手动校准，消除零点漂移
2. **指令系统**：自定义串口指令协议，支持实时状态查询和控制
3. **USB HID协议**：完整实现Joystick报告描述符
4. **低功耗设计**：支持多种省电模式

### 应用场景

- 无人机地面站控制
- 无人船遥控系统
- 工业自动化控制
- 机器人远程操控

### 技术栈

- **硬件**: STM32系列单片机
- **软件**: STM32 HAL库
- **协议**: USB HID (Joystick), 自定义串口协议
- **工具**: STM32CubeMX, Keil MDK

## 总结

| 项目 | 硬件平台 | 核心技术 | 应用领域 |
|------|---------|---------|---------|
| 串口屏网络状态显示 | JY1560串口屏 + Python | 串口通信, 协议设计 | 路由器状态监控 |
| RS485温湿度采集 | ESP32-S3 + 4.3寸屏 | RS485, Modbus | 环境监测 |
| STM32多功能控制器 | STM32 + USB HID | USB协议, HID | 无人机地面站 |

这三个项目展示了从简单串口通信到复杂USB协议实现的完整嵌入式开发能力，涵盖了上下位机协同、传感器数据采集、人机交互等多个技术领域。
